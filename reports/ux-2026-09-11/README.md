# تحویل محلی بهبود کالکیلو — ۲۰۲۶-۰۹-۱۱

نسخه قابل بررسی در **http://localhost:4173/fa/** از خروجی استاتیک `out` اجرا می‌شود. تولید، خرید، نصب، کمپین و تنظیمات DNS/CDN تغییر نکردند. Pages Router و React موجود حفظ شدند؛ مهاجرت یا بازنویسی فریم‌ورک انجام نشد.

## نتیجه

| مشکل | تغییر و دلیل |
|---|---|
| کلیک دانلود به موقعیت اشتباه می‌رسید | علت در مرورگر محلی بازتولید شد: `downloadTop=3331.55px` بعد از کلیک. با حذف content-visibility/ارتفاع جایگزین، مرورگر به مقصد رسید. اکنون بخش‌ها در جریان کامل layout هستند، تصاویر اندازه مشخص دارند و hash با رفتار بومی مرورگر کار می‌کند؛ هیچ تأخیر یا اسکرول اجباری اضافه نشد. |
| منوی موبایل وجود نداشت | منوی مشترک با امکانات، اشتراک، راهنما و پشتیبانی؛ کنترل Escape، برگشت فوکوس، انتخاب لینک، کلیک بیرون و خروج فوکوس. |
| معرفی طولانی و CTA مبهم | صفحه اصلی فارسی: عنوان عمومی قبلی، زیرعنوان کوتاه، بازار/مایکت/iPhone، توضیح خرید درون‌برنامه‌ای نزدیک CTA، نمونه فرایند و سه گام. تزئینات، کاروسل خودکار و ادعاهای جامعه/طرح تأییدنشده از مسیر اصلی فارسی کنار رفتند. |
| نمونه و تصویر مبهم | نمونه فارسی مشترک در خانه و صفحه عکس؛ صریحاً تصویرسازی و داده مرجع است، نه اسکرین‌شات یا نتیجه زنده AI. دکمه نمونه فقط توضیح مرور نتیجه را باز می‌کند. |
| اطلاعات قیمت/قابلیت تأییدنشده | قیمت ریالی قبلی در فایل منبع باقی ماند ولی Offer و کارت تأییدنشده فارسی نمایش داده نمی‌شود. اتصال سلامت فقط Apple Health با نسخه و پلتفرم اثبات‌شده معرفی می‌شود. ادعای رمزگذاری ذخیره حذف شد. |
| برند/فونت و تم ناسازگار | نشان واحد بدون فیلتر مخرب، Vazirmatn محلی با دو وزن و مجوز، فاصله و تیتر خواناتر، فوتر مشترک و اصلاح کنتراست روشن/تیره. |
| صفحه عکس ارزشمند | URL، title، H1 و canonical بدون تغییر؛ توضیح «در اپ» و مرز رایگان نزدیک بالا؛ نمونه فارسی پیش از کارت‌های محتوایی. |
| داده‌های غذا | پاسخ و مبنا پیش از CTA؛ چهار صفحه دارای ردیف مرجع قابل ردیابی، مقادیر بدون منبع کباب حذف و نیاز به دستور مشخص توضیح داده شد. جزئیات در جدول واقعیت محصول. |
| تماس mailto | توضیح پیش از فیلدها، دکمه «باز کردن برنامه ایمیل»، کپی آدرس/متن، خطای قابل فهم کپی؛ ادعای ارسال موفق وجود ندارد. |
| بلاگ | فهرست خودکار بخش‌ها برای مقاله طولانی، برچسب‌های فارسی، لینک مرتبط به کاربرد اپ، حفظ تاریخ/تحریریه/منابع؛ تصریح اینکه منابع عمومی مدرک تک‌تک ادعاها نیستند. |
| analytics پراکنده | listener و صف مشترک؛ تمام صفحات زیر `_app` پوشش ساختاری دارند. کلیک دانلود به analytics وابسته نیست. نام‌گذاری و محدودیت‌های سنجش مستند است. |
| build با واکشی زنده CMS | حالت صریح `CALKILO_OFFLINE_BUILD=1` با اعتبارسنجی snapshot موجود؛ build بررسی بدون شبکه/credential و بدون تغییر sitemap یا داده بلاگ اجرا شد. رفتار عادی انتشار تغییر نکرده است. |

## نتیجه آزمون‌ها

- **build:** موفق؛ ۳۱۹ صفحه استاتیک تولید شد. [خروجی واقعی](./build.txt).
- **lint:** موفق، بدون خطا یا هشدار. [خروجی](./lint.txt).
- **seo:audit:** موفق برای ۱۱۶ URL canonical؛ HTML اولیه زبان/RTL، canonical، hreflang واقعی و متقابل، sitemap/schema و عنوان محافظت‌شده بررسی می‌شوند. [خروجی](./seo-audit.txt).
- **مرورگر Chrome:** ۷ مسیر × ۴ عرض (۳۶۰، ۳۹۰، ۷۶۸، ۱۴۴۰) × دو تم = ۵۶ حالت. خانه، عکس، همبرگر، آرشیو بلاگ، مقاله نمونه، تماس و بخش اشتراک. overflow و بیرون‌زدگی تیتر/لینک در نمونه‌ها دیده نشد. axe با تگ‌های WCAG A/AA در این ماتریس تخلفی گزارش نکرد؛ این تأیید جامع WCAG نیست.
- **۲۷ آزمون رفتار:** اولین کلیک، ورود مستقیم، بین صفحات و Back برای دانلود/اشتراک؛ Escape و فوکوس منو، FAQ با صفحه‌کلید، تعامل نمونه و عدم تکرار مشاهده با hash، صف تک‌رویدادی بازار در خانه/عکس/غذا با analytics مسدود، کپی آدرس/پیام، نبود اطلاعات فرم در analytics، شواهد پنج غذا، حفاظت metadata و لینک‌های فروشگاه با JavaScript خاموش: قبول.
- مقصد واقعی فروشگاه‌ها با GET/HEAD و شناسه بسته/نسخه تطبیق داده شد. در تست کلیک، پنجره مقصد باز و شبکه فروشگاه عمداً متوقف شد؛ خرید/نصب انجام نشد. [شواهد HTTP](./evidence/http.json).
- آزمون تکمیلی: مسیر قدیمی `/fa/pricing/` به بخش درست رسید؛ تعویض زبان صفحه عکس به انگلیسی و بازگشت فارسی مقصد معادل را حفظ کرد؛ کلیک اول دانلود در عرض‌های ۳۶۰، ۷۶۸ و ۱۴۴۰ نیز درست بود. هدف لمس کنترل‌های منو و دانلود حداقل ۴۴px بررسی شد. [شواهد](./extended-checks.json).
- منطق ابزارهای BMI/کالری تغییر نکرد؛ بومی‌سازی این ابزارها طبق دامنه درخواست، کار مرحله بعد است.
- [جزئیات ماشین‌خوان آزمون مرورگر](./browser-audit.json)، [خلاصه](./browser-summary.txt)، [وضعیت پایه و متادیتا/CTA](./baseline.json).

اندازه‌گیری آزمایشگاهی: Chrome 152، viewport برابر ۳۹۰×۸۴۴، CPU چهار برابر کندتر، شبکه ۱٫۶ Mbps و تأخیر ۱۵۰ms، کش سرد، سه اجرا، سرور محلی Python بدون فشرده‌سازی و analytics مسدود. صفحه اصلی: LCP برابر ۲٫۹۰، ۲٫۶۱ و ۲٫۶۴ ثانیه (میانه ۲٫۶۴)، CLS حدود ۰٫۰۰۳۰. صفحه عکس: ۲٫۶۲، ۲٫۸۰ و ۲٫۷۶ ثانیه (میانه ۲٫۷۶)، CLS حدود ۰٫۰۰۲۴. بنابراین زیر ۲٫۵ ثانیه بودن LCP حتی در این آزمایش ادعا نمی‌شود. [داده خام](./lab-metrics.json).

در اولین اجرای سرد، مجموع بدنه منابع مشاهده‌شده: JS خانه حدود ۵۲۹ KiB و صفحه عکس ۷۷۱ KiB؛ CSS حدود ۷۷ KiB؛ دو فونت حدود ۹۹ KiB؛ تصاویر حدود ۶٫۵ KiB (عمدتاً نشان/آیکن؛ نمونه اصلی CSS است). این اعداد شامل prefetchهای Next در بازه مشاهده‌اند و gzip/Brotli تولید نیستند. اسلاید دوم در مسیر اصلی فارسی درخواست نمی‌شود و کاروسل خودکار حذف شده است. برای سنجش تولید باید فشرده‌سازی، شبکه واقعی ایران، منابع ثالث و داده کاربران واقعی جدا کنترل شوند؛ بهبود سرعت نسبت به baseline اندازه‌گیری نشده است. **field و INP واقعی اندازه‌گیری نشده‌اند**. رتبه، نصب یا رشد تبدیل پیش‌بینی نمی‌شود.

## مشاهده و مقایسه

[گالری قبل/بعد در مرورگر](http://127.0.0.1:4175/ux-2026-09-11/comparison.html) ([فایل محلی](./comparison.html)) تصاویر موبایل ۳۹۰ و دسکتاپ ۱۴۴۰ را کنار هم نشان می‌دهد. همه تصاویر پایه مربوط به کد اولیه این مخزن پیش از تغییر هستند؛ سایت زنده به‌طور جدا فقط برای منابع و HTTP دوباره بررسی شد. تصاویر بعد، از خروجی استاتیک نهایی و نه سرور توسعه گرفته شده‌اند. نمونه مقاله در آزمون نهایی اضافه شد؛ برای آن تصویر پایه ثبت نشده است.

## وابستگی‌های باقی‌مانده

1. **محصول:** رفع اختلاف IRR/تومان میان API عمومی طرح‌ها و سایت و تأیید مبلغ نهایی خرید ایران، دسترسی/سهمیه هر طرح، شرایط تمدید و بازپرداخت و تست عملی قابلیت‌ها در هر فروشگاه. تا تأیید، وعده یا عدد جدیدی به صفحه اضافه نشود.
2. **تصویر واقعی:** اسکرین‌شات فارسی نسخه فعلی با وعده ایرانی و داده غیرشخصی، همراه تأیید نسخه و حق استفاده. دمو فعلی صریحاً نمایشی است؛ به‌عنوان تصویر واقعی محصول تحویل نشده.
3. **داده غذا:** دستور و وزن قابل استناد کوبیده و نمونه‌های غذای ترکیبی ایرانی برای پاسخ عددی؛ عدد حدسی ساخته نشد.
4. **میزبان:** گواهی معتبر www، سپس redirect یک‌مرحله‌ای HTTP/www به HTTPS اصلی. راه‌حل دقیق آماده است، اما هیچ تنظیمی اعمال نشده.
5. **اندازه‌گیری:** بررسی GA DebugView و تنظیم page_view در Enhanced Measurement برای جلوگیری از تکرار؛ اتصال وب به نصب/خرید نامعلوم؛ داده field و GSC query×page و پنجره‌های ۲۸روزه لازم است.

جدول قابلیت × پلتفرم × نسخه × مدرک و منابع عددی: [product-evidence.md](./product-evidence.md). قرارداد رویدادها، KPI، منابع معیارها و دستور میزبان: [events-and-hosting.md](./events-and-hosting.md).

## بازبینی و بازگشت تغییرات

تغییرات در چهار گروه فایل قابل بررسی نگه داشته شده‌اند؛ commit یا push انجام نشده است:

1. ظاهر/ناوبری: SiteHeader، LandingPage، PersianHomeContent، PersianSample، globals.css، site-language و فونت‌ها.
2. محتوا/اعتماد: ResourcePage و resource-pages، FoodCaloriePage و food-calorie-pages، contact، BlogMarkdown/BlogDetailPage/BlogCard و blog-copy، features و product-facts.
3. سنجش: analytics و `_app`؛ تغییرات حذف handlerهای قبلی در LandingPage و ResourcePage همراه آن بررسی شوند.
4. ابزار تحویل: حالت offline در prebuild، audit-export و دو اسکریپت QA. گزارش‌ها و تصاویر خروجی جدا هستند.

برای بازگشت انتخابی، diff هر گروه را بررسی و با توجه به تغییرات جدید کاربر revert کنید؛ برگشت همه فایل‌ها بدون بازبینی توصیه نمی‌شود. پروژه‌های اپ و بک‌اند و فایل‌های داده/پیکربندی تولید و package-lock تغییر نکردند.

## اجرای دوباره

```sh
CALKILO_OFFLINE_BUILD=1 npm run build
npm run lint
npm run seo:audit
python3 -m http.server 4173 --bind 127.0.0.1 --directory out
# برای گالری، در ترمینال جدا:
python3 -m http.server 4175 --bind 127.0.0.1 --directory reports
```

در ترمینال دیگر، وابستگی QA را بیرون پروژه نصب کنید؛ Chrome محلی لازم است:

```sh
npm install --prefix /tmp/calkilo-qa playwright @axe-core/playwright --no-audit --no-fund
CALKILO_QA_RUNTIME=/tmp/calkilo-qa/node_modules node scripts/ux-browser-audit.cjs
CALKILO_QA_RUNTIME=/tmp/calkilo-qa/node_modules node scripts/ux-lab-metrics.cjs
```

دو آزمون مرورگر و سرعت را هم‌زمان اجرا نکنید؛ مصرف CPU آزمون دیگر اندازه‌گیری سرعت را مخدوش می‌کند. اسکریپت‌ها خروجی همین پوشه را به‌روز می‌کنند.
